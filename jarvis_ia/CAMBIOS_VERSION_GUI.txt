QUÉ HACE AHORA:

- Jarvis tiene una ventana visual con chat, entrada de comandos, botón para hablar y accesos rápidos.
- Jarvis puede crear interfaces en:
  - Python Tkinter
  - Java Swing
  - HTML/CSS/JS
